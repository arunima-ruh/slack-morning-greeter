# Slack Morning Greeter ☀️

Automated morning greeting sent to Slack every weekday at 10 AM IST.

> Auto-generated by [Agent Factory](https://github.com/openclaw/agent-factory).

## Quick Start

### Prerequisites

- Node.js 22+ and npm
- OpenClaw installed ([docs](https://docs.openclaw.ai))
- Slack bot token ([create here](https://api.slack.com/apps))
- (Optional) PostgreSQL for greeting history tracking

### Local Setup

```bash
# Clone the repository
git clone <repo-url>
cd slack-morning-greeter

# Install dependencies
./install-dependencies.sh

# Configure environment
cp .env.example .env
# Edit .env with your SLACK_BOT_TOKEN and SLACK_CHANNEL

# Validate setup
./check-environment.sh

# (Optional) Provision database schema
python3 scripts/data_writer.py provision

# Copy to OpenClaw workspace
cp -r . ~/.openclaw/workspace/slack-morning-greeter/

# Test the workflow
openclaw workflow run workflows/main.yaml

# Start OpenClaw with cron enabled
openclaw start
```

## Configuration

### Required Environment Variables

| Variable | Description | Example |
|----------|-------------|---------|
| `SLACK_BOT_TOKEN` | Slack bot token | `xoxb-...` |
| `SLACK_CHANNEL` | Target Slack channel | `PERSONAL` or `#general` |

### Optional Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `PG_CONNECTION_STRING` | PostgreSQL connection string for greeting history | Not set (agent works without DB) |
| `ORG_ID` | Organisation ID for database schema | `default` |
| `AGENT_ID` | Agent ID for database schema | `slack-morning-greeter` |

## Skills

| Skill | Type | Description |
|-------|------|-------------|
| `data-writer` | System | Handles all database operations |
| `greeting-composer` | Custom | Generates morning greeting message |
| `slack-sender` | Native Tool | Sends message via Slack (uses message() tool) |
| `log-writer` | Custom | Records delivery status to database |
| `result-query` | User-invocable | Query greeting history via chat |

## Scheduled Jobs

This system uses OpenClaw cron for scheduling:

| Job Name | Schedule | Description |
|----------|----------|-------------|
| `morning-greeting` | `30 4 * * 1-5` (10 AM IST, Mon-Fri) | Send morning greeting to Slack |

Manage jobs with:
```bash
openclaw cron list              # view all jobs
openclaw cron runs              # view run history
openclaw cron run --name morning-greeting  # trigger manually
openclaw cron disable --name morning-greeting  # pause
openclaw cron enable --name morning-greeting   # resume
```

## Workflow

```
1. Provision DB schema (first run only)
     ↓
2. Generate greeting message ("Good morning! ☀️")
     ↓
3. Send to Slack via message() tool
     ↓
4. Log delivery status to database
```

**Trigger:** Cron (weekdays 10 AM IST)

**Note:** Workflow does NOT execute in response to chat messages. Users can only query stored data via chat.

## Data Storage

Results are stored in your own PostgreSQL database (optional):

| Table | Purpose | Conflict Key |
|-------|---------|--------------|
| `result_greeting_log` | Tracks each greeting delivery | `date_key` |

Schema: `org_{ORG_ID}_a_{AGENT_ID}`

Query greeting history:
```bash
python3 scripts/data_writer.py query \
  --table result_greeting_log \
  --limit 10 \
  --order-by "sent_at DESC"
```

Or via chat:
- "Show my recent greetings"
- "Did the greeting send today?"
- "Show failed deliveries"

## Customization

### Change the greeting message

Edit `workspace/skills/greeting-composer/scripts/run.sh`:

```bash
MESSAGE="Your custom greeting here!"
```

### Change the schedule

Edit `cron/morning-greeting.json`:

```json
{
  "schedule": "0 9 * * *",  // 9 AM UTC daily
  "timezone": "UTC"
}
```

### Change the channel

Update `.env`:

```bash
SLACK_CHANNEL=#your-channel
```

## Troubleshooting

### Greeting not sending

1. Check Slack token: `echo $SLACK_BOT_TOKEN`
2. Verify bot has permission to post in the channel
3. Check cron logs: `openclaw cron runs`
4. Test manually: `openclaw cron run --name morning-greeting`

### Database errors

1. Check connection string: `echo $PG_CONNECTION_STRING`
2. Provision schema: `python3 scripts/data_writer.py provision`
3. Test connection: `psql $PG_CONNECTION_STRING -c "SELECT 1"`

### Environment validation fails

Run `./check-environment.sh` and fix reported issues.
